# Security Policy

The detailed security model, trust boundaries and backup gate are documented
in [docs/SECURITY.md](docs/SECURITY.md).

## Supported versions

Security fixes are provided for the latest published release and the current
`main` branch. Releases in the `0.0.x` series remain pre-production software.

## Reporting a vulnerability

Do not disclose suspected vulnerabilities, migration data or exposed secrets
in a public issue. Use GitHub's private vulnerability reporting feature and
include the affected version, impact, reproduction steps and any suggested
mitigation.

Never attach production CSV files, exported ticket content, credentials or
database dumps to an issue.
